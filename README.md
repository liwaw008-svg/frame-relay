# Frame Relay

Fragments arrive out of order. The relay discovers whether their poses can carry motion from one hand to the next.

A conductor freezes the pose vocabulary and creator addresses. Each creator contributes one animation fragment in ordinary language. Validators map every fragment to entry pose, exit pose, and bounded duration. Contract code explores every possible ordering and stores the longest compatible chain, with a public lexicographic tie-break.

All fragments linked yields `COMPLETE`; otherwise the best surviving sequence is `PARTIAL`. The model cannot choose the chain.

Live creator wallets are operator-controlled role fixtures, not independent artists.
